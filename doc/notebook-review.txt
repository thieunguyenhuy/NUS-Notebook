NUS Notebook review — 2026-10-28

Changes
- Enabled all 12 content chapters in content/kactl.tex. Each chapter now lists all
  its source/text files and includes its reference diagrams. Removed the missing
  FastSegmentTree.h import. Shared build assets in content/tex and the standalone
  test-session document wrapper are not printed as notebook listings.
- Fixed SuffixArray's nonexistent get() call, unsigned character ordering, and
  LCP reads past string boundaries (including embedded NUL characters).
- Initialized FastSet storage, supplied init(), removed undefined shifts by 64,
  and removed dependencies on undefined bit-operation macros.
- Fixed iterative lazy segment-tree right-boundary propagation/rebuilding and
  lazy composition destination. TT/UT/UU remain problem-specific methods to define.
- DsuRollback now records redundant unite() calls so rollback(k) agrees with
  TimeSegmentTree's contract. IMPORTANT: k counts ALL unite calls, not just
  successful merges. Restored the separate snapshot-based RollbackUF API used by
  DirectedMST; its rollback argument is a saved time, not an operation count.
- Restored RMQ and LazySegmentTree from this repository's history, fixing missing
  production dependencies in LCA, CompressTree and HLD. The lazy tree does not
  force the global bump allocator onto callers.
- PersistentLazyIT now has a dynamic node pool instead of undefined N/LG bounds,
  preserves existing node versions during updates, accepts 64-bit update values,
  and performs queries without allocations. Dynamic allocation makes update
  complexity amortized O(log N). Added a pool-capacity assertion to PersistentIT.
- Matrix now reduces multiplication results before they can feed another product,
  normalizes signed input, handles empty matrices, and checks exponentiation
  dimensions. Configure Matrix::MOD (default 1e9+7); entries assigned through []
  must already be reduced, and 8*MOD*MOD must fit in signed 64-bit.
- Replaced overflow-prone CHT cross products with 128-bit arithmetic and removed
  redundant intersection ties. Normal line evaluations must still fit in ll.
- Fixed INT_MIN deletion overflow and detached-node leaks in the explicit treap;
  freed removed nodes in the implicit treap. Explicit erase removes all equal keys.
- MaxFlow::minCut now returns only positive-capacity original edges, excluding
  zero-capacity residual reverse edges. Guarded equal flow source and sink.
- Removed missing macro/type dependencies from custom matching, 2-SAT, flow,
  primality and FFT snippets. FFT::MOD is configurable (default 1e9+7); rounded
  convolution coefficients must fit in signed 64-bit and floating precision.
- NTT now uses a power helper with its actual 998244353 modulus. Modular square
  root has its own modulus-aware helper and handles p=2.
- Reset GF(2) Gaussian-elimination answers and palindromic-tree state between
  uses; enlarged the palindromic-tree arrays for their sentinel/root overhead.
- Fixed repeated FT2 initialization and INT_MAX y-coordinate queries while
  preserving its documented inclusive query convention; updated the old test
  to use that convention. Empty virtual-tree subsets and degenerate geometric
  segments/polygons now behave safely.
- Fixed hashing's ull typedef conflict with the stress-test template and made
  the Codeforces hash conversion operator const-correct.
- Added explicit <cassert> to the contest template for current GCC versions.
  Normalized shell scripts and the skip list to Unix line endings: CRLF broke
  both hash generation and the compile exclusion list.
- Corrected a missing zero in Bezout's identity, the variable in the power-sum
  identity, the first-kind Stirling-number table, and two spelling errors.
