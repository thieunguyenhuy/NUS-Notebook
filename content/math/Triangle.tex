For a triangle made up of three points $A,B,C$, denote:
\begin{itemize}
    \item $a = |AB|, b = |BC|, c = |CA|,$ $\displaystyle s = \frac{a+b+c}{2}$

    \item $\angle A = \angle BAC, \angle B = \angle ABC, \angle C = \angle ACB$

    \item $R$ as the radius of the circumcircle.

    \item $r$ as the radius of the incircle.

    \item $A$ as the area of the triangle.
\end{itemize}

Then, some useful formulas are:
\begin{itemize}
    \item $\displaystyle A = \sqrt{s(s - a)(s - b)(s - c)} = rs = \frac{abc}{4R}$

    \item $\displaystyle 2A = ab \sin (\angle A) = bc \sin (\angle B) = ca \sin (\angle C)$

    \item $\displaystyle \frac{a}{\sin (\angle A)} = \frac{b}{\sin (\angle B)} = \frac{c}{\sin (\angle C)} = 2R.$

    \item $a^2 = b^2 + c^2 - 2bc \cos (\angle A), b^2 = c^2 + a^2 - 2ca \cos (\angle B),$
    $c^2 = a^2 + b^2 - 2ab \cos (\angle C)$
\end{itemize}
