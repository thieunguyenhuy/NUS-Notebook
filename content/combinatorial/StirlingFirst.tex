Denote $c(n, k)$ as no. of permutations length n with $k$ cycles on the permutation graph $p_i$ -- $i$. Formulas below:
\begin{itemize}
    \item $c(n, k) = c(n - 1, k - 1) + (n - 1)c(n - 1, k),\ c(0, 0) = 1$
    
    \item $\displaystyle \sum_{k = 0}^n c(n, k)x^k = x(x + 1) \dots (x + n - 1)$
\end{itemize}
$c(8, k) = 0, 5040, 13068, 13132, 6769, 1960, 322, 28, 1$
